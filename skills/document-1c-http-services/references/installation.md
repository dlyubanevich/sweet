# Install sweet-cli

This skill requires `sweet-cli` 1.1.0 or newer. Install the executable separately from the skill directory.

## Published binary

Check the repository's release page for an asset matching the exact CLI version, operating system, and CPU architecture:

<https://github.com/dlyubanevich/sweet/releases>

Download an asset only when the release page actually lists that combination. Put the extracted `sweet-cli` (or `sweet-cli.exe`) in a directory on `PATH`, then verify it:

```console
sweet-cli --version
sweet-cli --help
```
